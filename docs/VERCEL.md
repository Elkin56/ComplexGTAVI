# Деплой на Vercel: пошаговая инструкция

## 0. Прежде чем начать

- **Тариф.** Бесплатный Hobby у Vercel только для личных некоммерческих проектов. Акция магазина считается коммерческим использованием, нужен **Pro** (около $20/мес, актуальную цену смотрите на vercel.com/pricing).
- **Cron на Hobby** работает только раз в сутки (поэтому в `apps/web/vercel.json` стоит `0 9 * * *`: 09:00 UTC = 12:00 по Москве). На Pro можно поставить `0 * * * *`.
- Нужны: аккаунт GitHub, аккаунт Vercel, бот от @BotFather, ваш Telegram ID (узнать у @userinfobot), Node.js 22 на вашем компьютере (для миграции и настройки бота).

## 1. Код в GitHub

```bash
tar xzf complex-pc.tar.gz && cd complex-pc
git init && git add . && git commit -m "init"
# создайте пустой приватный репозиторий на GitHub и выполните:
git remote add origin git@github.com:ВАШ_АККАУНТ/complex-pc.git
git branch -M main && git push -u origin main
```

## 2. Бот

В @BotFather: `/newbot` → имя и username → сохраните **токен** (это `BOT_TOKEN`). Запомните username бота: из него получится `NEXT_PUBLIC_BOT_URL=https://t.me/username_бота`.

## 3. Проект в Vercel

1. Add New → Project → выберите репозиторий.
2. **Root Directory: `apps/web`** (Edit рядом с полем). Включите «Include source files outside of the Root Directory» (обычно включено): без этого не соберётся пакет `packages/core`.
3. Framework Preset: Next.js (определится сам). Install/Build Command не меняйте.
4. Project Settings → General → Node.js Version: **22.x**.
5. **Имя проекта** выберите сразу: адрес будет `https://ИМЯ.vercel.app`, он нужен для `APP_URL`.
6. Пока **не нажимайте Deploy**: сначала база и переменные (шаги 4 и 5).

## 4. База данных

Project → Storage (или Marketplace) → **Neon Postgres** → Create → Connect to Project. Регион выберите ближе к пользователям (например, Frankfurt) и **тот же регион для функций**: Settings → Functions → Region.
Vercel добавит переменные подключения. Нужны две:

- `DATABASE_URL`: **pooled** (через pgbouncer), её использует приложение;
- `DATABASE_URL_UNPOOLED`: прямая, нужна только для миграций.

(Если имена отличаются, смотрите в Neon: Connection Details, переключатель «Pooled connection».)

## 5. Переменные окружения (Settings → Environment Variables, окружение **Production**)

| Переменная | Значение |
|---|---|
| `DATABASE_URL` | уже добавлена Neon (pooled) |
| `BOT_TOKEN` | токен от BotFather |
| `WEBHOOK_SECRET` | случайная строка, `openssl rand -hex 24` |
| `CRON_SECRET` | случайная строка от 16 символов, `openssl rand -hex 24`. Vercel сам отправит её в заголовке при запуске cron |
| `APP_URL` | `https://ИМЯ.vercel.app` или ваш домен. Без `/` в конце, только https |
| `ADMIN_TELEGRAM_IDS` | ваш Telegram ID. Несколько: `111,222`. Эти люди становятся OWNER |
| `NEXT_PUBLIC_BOT_URL` | `https://t.me/username_бота` (вшивается при сборке) |
| `RECEIPT_API_URL`, `RECEIPT_API_TOKEN` | только если подключаете кассу/1С |

**Не задавайте** `DEV_AUTH_BYPASS` и `NEXT_PUBLIC_DEV_USER_ID` в production. После любого изменения переменных нужен **Redeploy**: старые деплои их не видят.

## 6. Миграции (один раз, с вашего компьютера)

```bash
npm install
# macOS/Linux:
DATABASE_URL="ПРЯМАЯ_unpooled_ссылка" npm run db:migrate -w @complex/web
# Windows PowerShell:
$env:DATABASE_URL="ПРЯМАЯ_unpooled_ссылка"; npm run db:migrate -w @complex/web
```

Нужна именно **прямая** ссылка: через pooled миграции зависают. Успех: «All migrations have been successfully applied». После изменений схемы повторяйте это перед деплоем.

## 7. Деплой

Нажмите Deploy (или Redeploy, если уже деплоили). Проверка в браузере (лучше в режиме инкогнито):

`https://ИМЯ.vercel.app/api/health` → `{"ok":true,"db":"ok","config":"ok","bot":"configured",...}`

Если открывается страница входа Vercel: Settings → Deployment Protection, у Production не должно быть защиты паролем или Vercel Authentication.

## 8. Подключение бота

Создайте файл `apps/web/.env` (в git он не попадёт) только с тремя строками:

```
BOT_TOKEN=...
APP_URL=https://ИМЯ.vercel.app
WEBHOOK_SECRET=...        # то же значение, что в Vercel
```

```bash
npm run bot:setup -w @complex/web
```

Скрипт зарегистрирует вебхук, кнопку «Открыть» и команду `/start`. Вывод заканчивается ссылкой на бота. Проверка вебхука: `https://api.telegram.org/bot<ТОКЕН>/getWebhookInfo`: поле `last_error_message` должно быть пустым.

Повторяйте `bot:setup` при смене `APP_URL` (например, после подключения домена) или `WEBHOOK_SECRET`.

## 9. Подключение админ-панели

1. Ваш Telegram ID должен быть в `ADMIN_TELEGRAM_IDS` (шаг 5), после чего сделан Redeploy.
2. Откройте бота → `/start` → «Открыть приложение» → примите правила.
3. **Профиль → «Админ-панель»**. Кнопка видна только сотрудникам. Роль OWNER присваивается автоматически.
4. Других сотрудников добавляйте там же: **Сотрудники** → Telegram ID → роль. Они получат доступ после первого входа в приложение.

| Роль | Что может |
|---|---|
| STAFF | заявки (подтвердить/отклонить), ручная выдача, участники, статистика |
| MANAGER | + отмена покупок, журнал, экспорт |
| OWNER | + настройки акции, запуск, закрытие приёма, финал, сотрудники |

Кнопки нет? Проверьте: ID верный и без пробелов; после правки переменных был Redeploy; вы открыли именно этого бота.

## 10. Настройки акции (Админ-панель → Настройки акции)

Заполните, **сохраните**, и только потом нажмите «Запустить акцию».

- **Название:** «Розыгрыш PS5 + GTA 6».
- **Дата начала:** с этого дня 00:00 принимаются чеки. Покупки раньше не засчитываются. После запуска её менять нельзя.
- **Дата финала:** день, в 00:00 которого приём заканчивается. Для «финал 1 декабря» ставьте `2026-12-01`: чеки на покупки до 30 ноября включительно. Если нужно принимать и покупки 1 декабря, поставьте 2 декабря. Таймер на главной считает до этого момента.
- **Часовой пояс:** по поясу магазина, например `Europe/Moscow` или `Europe/Samara`. После запуска не меняется.
- **Ссылка на эфир:** `https://...` (можно добавить позже, кнопка на главной появится сразу).

До запуска пользователи видят «Акция скоро начнётся» и чек отправить не могут.

## 11. Проверка перед запуском (чек-лист)

1. `/api/health` зелёный.
2. `/start` в боте присылает кнопку, Mini App открывается внутри Telegram.
3. Правила и согласие показываются при первом входе, юрист текст утвердил (`apps/web/src/lib/rules.ts`).
4. Тестовый чек: отправили с одного аккаунта → в «Заявки» у сотрудника появился → подтвердили → билеты `CP-…` у пользователя, пришло уведомление в Telegram.
5. Повторная отправка того же чека отклоняется.
6. Экспорт открывает файл (Админ-панель → Экспорт).
7. Cron: `curl -H "Authorization: Bearer ВАШ_CRON_SECRET" https://ИМЯ.vercel.app/api/cron/reminders` → `{"sent":false,"reason":"not due"}` (до финала далеко, это нормально).
8. Тестовые данные удалите перед боем: в Neon выполните `TRUNCATE "ReminderLog","AuditLog","PurchaseClaim","Raffle","Ticket","Purchase","User" RESTART IDENTITY CASCADE; ALTER SEQUENCE ticket_number_seq RESTART WITH 1;` (таблицу `Admin` не трогайте, если уже добавляли сотрудников; после очистки заново задайте настройки акции).

## 12. Свой домен (желательно)

Vercel → Settings → Domains → Add. Затем обновите `APP_URL`, сделайте Redeploy и повторите `bot:setup`. Свой домен надёжнее открывается у пользователей, чем `*.vercel.app`.

## 13. Финал

1. Обработайте все заявки (пока есть необработанные, приём закрыть нельзя).
2. Админ-панель → Розыгрыш → «Закрыть приём чеков» (два нажатия).
3. «Показать список» / «Выгрузить в Excel»: сверьте номера с шариками в лототроне.
4. Введите выпавший номер → «Проверить владельца» → «Зафиксировать победителя». Результат необратим; победитель и участники получат уведомления.

## Ограничения Vercel, которые стоит знать

- **Рассылка** после финала идёт после ответа и ограничена длительностью функции (в проекте 60 секунд, примерно 1200 сообщений). Для больше аудитории разворачивайте на VPS (`docker-compose.yml`).
- **Размер запроса** до ~4,5 МБ: фото чека сжимается на телефоне до 1600 px, этого хватает.
- **Cron** на Hobby: раз в сутки, время в пределах часа, UTC.
- **Обновление:** `git push` в `main` деплоит автоматически. Если менялась схема БД, сначала выполните миграцию (шаг 6).
- **Резервные копии:** используйте восстановление на момент времени в Neon (на платных планах) или `pg_dump` с прямой ссылкой.

## Если что-то не работает

| Симптом | Причина и решение |
|---|---|
| В приложении «Сервер не настроен» | не заданы `BOT_TOKEN`, `WEBHOOK_SECRET`, `APP_URL` или `CRON_SECRET`; добавьте и сделайте Redeploy |
| «База данных недоступна» | неверный `DATABASE_URL`, база не создана или не применены миграции (шаг 6) |
| «Сессия устарела» | закройте Mini App и откройте заново из бота |
| «Откройте через Telegram» | страница открыта в обычном браузере |
| Бот молчит на `/start` | вебхук не зарегистрирован или секрет не совпадает: `bot:setup`, затем `getWebhookInfo` |
| Не приходят уведомления | пользователь заблокировал бота или не нажимал `/start`; смотрите логи: Vercel → Logs |
| Деплой падает с ошибкой cron | на Hobby расписание чаще раза в сутки запрещено; оставьте `0 9 * * *` |
| Сборка падает на `@complex/core` | выключена опция «Include source files outside of the Root Directory» |
